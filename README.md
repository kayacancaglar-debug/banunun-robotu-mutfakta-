# Banu’nun Robotu Mutfakta 🤖🍲

3 kişilik mevsimlik Türk mutfağı akşam yemeği Android uygulaması.

## APK oluşturma

Depoya bu klasörün **içindeki tüm dosyaları** kök dizine yükle. GitHub Actions otomatik başlar.
Actions > Banu Android APK > başarılı çalıştırma > Artifacts > Banunun-Robotu-Mutfakta-APK.
İndirilen ZIP’in içinde app-debug.apk bulunur. APK'yı telefona kurabilirsin.

Bu sürüm hazır menülerle çalışır; günlük yapay zeka üretimi ve canlı mevsim/veri denetimi içermez.
